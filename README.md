# Harbor Goods — HTML demo store

A minimal static e-commerce front end: product grid, `localStorage` cart, no build step.

Use it as a throwaway GitHub repository for testing crawlers, audits, or automation that expects a simple storefront.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```
